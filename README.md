## Four Paws Friends Website

This project is a fully responsive multi-page website created for the fictional animal rescue organization Four Paws Friends. The website serves as an informational and fundraising platform, providing users with easy access to adoption details, events, donation forms, and contact information.
All functionality and layout are implemented using clean front-end code, built for accessibility, clarity, and modern design.

## 🛠️ Technologies

HTML5: Structures all pages, sections, content, and navigation.
CSS3: Handles styling, layout improvements, visuals, and custom design.
Bootstrap 5: Provides responsive grid, components, navigation bar, cards, and carousel.
Font Awesome: Supplies icons used across the site (social icons, paw icon, etc.).
Google Fonts: Manages the website’s typography.

## 📦 Content

The project contains multiple HTML pages and corresponding assets, structured as follows:

index.html — Homepage with carousel, intro text, cards, testimonials, and newsletter.

about-us.html — Information about the organization, gallery, mission, and team.

events.html — List of upcoming and past events.

donate.html — Donation page with forms and instructions.

contact-us.html — Contact form and organization info.

admin-login.html — A front-end login page for administrators.

admin.html — The Admin Dashboard, featuring a fixed top navigation, sidebar, summary cards, and a data table.

css/styles.css — Custom styling file uploaded separately by user.

img/ — Folder containing all images (logo, animals, carousel photos, etc.).

## 🚀 Execution Guide

No server or backend environment is required.
You can run the website directly in your browser.

Steps:

Place all project files in the same project folder, keeping this structure:

index.html

about-us.html

events.html

donate.html

contact-us.html

/css/styles.css

/img/*

admin-login.html

admin.html

Open index.html with any modern browser (Chrome, Edge, Firefox, Safari).

Navigate through the website using the navbar or buttons.
